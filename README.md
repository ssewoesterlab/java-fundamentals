# Java Fundamentals ☕

**Java-Übungen zur Vorbereitung auf eine Ausbildung zum Fachinformatiker für Anwendungsentwicklung (2027).**

In diesem Repository dokumentiere ich meine Lernfortschritte mit Java. Die Übungen behandeln grundlegende Programmierkonzepte und kleine Konsolenprogramme.

## 🧰 Technologien

- Java 21
- Maven
- IntelliJ IDEA
- Git und GitHub

## ▶️ Ausführen

1. Repository klonen:
   ```bash
   git clone https://github.com/ssewoesterlab/java-fundamentals.git
   ```
2. Den Projektordner in IntelliJ IDEA öffnen und als Maven-Projekt laden.
3. JDK 21 auswählen.
4. Die gewünschte Java-Klasse im Ordner `src/main/java` öffnen und ihre `main`-Methode ausführen, sofern vorhanden.

## 🎯 Lernziele

- Kontrollstrukturen, Schleifen und Methoden sicher anwenden
- Mit Strings und Arrays arbeiten
- Probleme in überschaubare Teilschritte zerlegen
- Code nachvollziehbar dokumentieren und mit Git versionieren

> **Hinweis:** Das Repository enthält Lern- und Übungsprogramme, keine produktionsreifen Anwendungen.
